# Notes From a Passive-Aggressive Fridge

One dry, petty note a smart fridge leaves on its door screen for its owner:
the leftover pizza has now outlived some of the fridge's own firmware versions.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the note (single line, 1–200 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
